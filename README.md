Entry for the make.fun bounty [The Router Confesses](https://make.fun/c/u-carbon-forge-the-router-confesses-f98f6b9e).

`main.py` (Python 3.13, program/v1) deterministically writes a single
112-character line to `/output/entry.txt`: a home Wi-Fi router's excuse for
dropping the connection at a movie's climax. No network, no randomness, no
input — two runs produce byte-identical output.

Run locally:

```bash
python3 main.py
cat /output/entry.txt
```
